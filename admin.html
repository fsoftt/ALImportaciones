Configurar acceso

Esto se hace una sola vez. Pega la clave de GitHub y crea el usuario y la contraseña con los que entrarás al panel.

¿Cómo obtengo la clave de GitHub?
  1. Inicia sesión en GitHub con una cuenta que tenga acceso al repositorio .
  2. Abre Crear token (fine-grained).
  3. En Expiration elige la fecha más lejana posible.
  4. En Repository access elige Only select repositories y selecciona el repositorio.
  5. En Permissions → Repository permissions pon Contents: Read and write.
  6. Genera el token, cópialo y pégalo aquí.

La clave se guarda cifrada con tu contraseña: sin la contraseña no sirve.
